Features

Everything you need,
nothing you don't

Seven tools unified in one clean workspace. No context switching, no subscriptions, no data leaving your machine.

Audio Transcription

Record directly or upload audio files. Powered by OpenAI Whisper, Groq, or AssemblyAI — choose your provider, bring your own API key.

Rich Notes

Full markdown editor with Mermaid diagrams, code blocks, tables, and [[backlinks]]. Publish notes with a single click.

Task Management

Priorities, due dates, and completion tracking. See everything on your calendar or manage flow with Kanban boards.

Kanban Boards

Visual project management with drag-and-drop columns and cards. Organize work your way.

Daily Journal

Capture thoughts with mood tracking and daily prompts. Convert entries into tasks or notes instantly.

Canvas

Infinite whiteboard powered by Excalidraw. Sketch ideas, create diagrams, and think visually.

Bookmarks

Save links with automatic previews. Includes a Chrome extension for one-click capture from any page.

AI Engine

Your voice, refined
by intelligence

Record or upload audio, get instant transcription, then optionally refine the output with AI — using your own API keys.

Multi-Provider

Choose between OpenAI Whisper, Groq, or AssemblyAI. Each provider brings different strengths — speed, accuracy, or specialization.

Smart Refinement

AI cleans up filler words, fixes grammar, structures paragraphs, and even auto-generates relevant tags from your content.

Custom Prompts

Tailor the AI behavior with custom system prompts. Medical terminology, meeting formatting, creative writing — make it yours.

Self-hosted means self-owned

Clarity runs entirely on your infrastructure. Your notes, transcripts, tasks, and journal entries never touch a third-party server. Deploy with Docker in under a minute.

Encrypted at Rest

API keys protected with AES-256-GCM. Secrets auto-generated, never hardcoded.

Single SQLite File

All your data in one portable file. Back up by copying a single file. No complex database setup.

Zero Telemetry

No analytics, no tracking, no phoning home. What happens on your server stays on your server.

Full Data Export

Export everything as JSON anytime. No vendor lock-in, no data hostage situations.

# Deploy Clarity in seconds

$ docker run -d \
  --name clarity \
  -p 3000:3000 \
  -v clarity-data:/app/data \
  firstfinger/clarity:latest

# That's it. Open localhost:3000
